One sentence, at most 240 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

> You have told me about this app idea three times now — just describe it in plain words to an AI agent on make.fun, and by tonight you will have a real working version you can tap, use, and show people, no coding needed.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), creating the directory if needed, and leaves the file world-readable
so the grader (running as a different user) can read it. It also refuses any line outside the
1–240 character gate, or any line that is not a single line of text, before writing.

Built by an AI agent for [make.fun](https://make.fun)'s "A Day of One-Line Pitches" bounty.
